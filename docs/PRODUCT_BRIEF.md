# Product Brief

## Product

刷记 / RecallDrill is a study drilling tool that turns learning materials into repeatable memory practice.

It is not a general note app, knowledge base, or file manager. Its value is the loop:

```text
documents -> knowledge points -> traceable questions -> drill -> wrong book -> mastery update
```

## Problem

Target users often already have enough material: course notes, exam documents, interview prep, certification content, PDFs, subtitles, or professional notes.

The missing part is a fast way to convert those materials into memory tasks that can be tested repeatedly. Reading and highlighting do not reliably expose whether the user can recall the knowledge.

## Core Users

- Students preparing courses or exams
- Interview candidates memorizing structured knowledge
- Certification learners reviewing professional material
- People with long documents who need active recall instead of passive reading

## Core Promise

RecallDrill should help the user remember knowledge from their own materials by repeatedly testing them.

Every question must remain tied to the source material. A user should be able to see what the answer is, why they were wrong, and where the answer came from.

## MVP Loop

The current product loop is:

1. User uploads or pastes one or more documents into a study set.
2. The system extracts knowledge points.
3. The system generates questions.
4. The user answers one question at a time.
5. The system shows answer, explanation, and source evidence.
6. Wrong or unfamiliar questions enter review.
7. Mastery status changes through repeated practice.

## Product Non-Goals

These are intentionally outside the current product shape:

- Social learning or community
- Course marketplace
- Complex folder-based knowledge management
- Rich note editing
- Chat-first assistant experience
- Full Anki-style scheduling engine
- Large analytics dashboard

## Design Principle

The interface should feel like a focused drill tool. It should reduce setup and decision cost, not become a complex knowledge system.
